On-Model Template Studio

The full workflow for adding a template: generate a pipeline-safe prompt, validate the AI image against the exact QA gates the build runs, try recolours live, then hand the approved image over to go live.

STEP 1

Generate the prompt

Every clause in the output maps to a validator check below — the prompt is strict because each rule prevents a specific pipeline failure we've hit before.

Inspiration image (optional) — click this box, then paste / drop a mockup you like. The scene, light and bottoms fields are drafted from it; edit before building.

STEP 2

Validate the image

Paste (Ctrl/Cmd-V anywhere on this page), drop, or pick the generated image. This runs the same analysis as the build pipeline — same thresholds, same verdicts. Validate the raw generation first; if it passes, upscale it, remove the watermark, and validate the final file again before handing it over.

Paste, drop, or click to load the candidate image
JPG / PNG / WebP · portrait · short side ideally ≥ 1300px
Corrected prompt

Same brief, with the clauses that just failed restated and hardened. Regenerate with this, then drop the new image back in.

STEP 3

Try recolours

Live recolour using the production maths. Check white and near-black hardest — they expose shading and shadow problems that mid colours hide.

Look for: violet residue anywhere · dark or pale rims along sleeves · washed patches in shadow folds · anything that pops that isn't in the photo.

STEP 4

Ship it

Everything is filled in already — the entry, the numbers this validator measured, and the prompt the image came from. Press the button, paste into the Claude session, attach the final image (upscaled, watermark-free). Nothing else should be needed.
